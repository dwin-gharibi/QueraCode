# Quera brand tokens

Sourced from Quera's official logo assets (the cyan geometric "Q").

| Token | Hex | Use |
| --- | --- | --- |
| `--quera-primary` | `#0099CC` | Quera cyan — the brand color (the "Q") |
| `--quera-primary-bright` | `#00B4E6` | brighter cyan for gradients/accents |
| `--quera-primary-dark` | `#007A9E` | pressed/hover, dark-on-light text |
| `--quera-primary-light` | `#CCEEFF` | tints, chip backgrounds |
| `--quera-ink` | `#0F172A` | dark surfaces / body text |
| `--quera-surface` | `#F6FAFD` | light surface |
| `--quera-muted` | `#64748B` | secondary text |
| `--quera-green` | `#10B981` | success / accepted verdict |
| `--quera-red` | `#EF4444` | error / failing verdict |
| `--quera-amber` | `#F59E0B` | warning |

Fonts: **Vazirmatn** (Persian/RTL), **Inter** (Latin), **JetBrains Mono** (code).

Logos: `quera-logo.svg` (the cyan Q mark), `quera-wordmark.svg` (the "quera"
wordmark), `logo.svg` (app-icon badge: white rounded square + cyan Q).
Diagrams use cyan accents on a white background.
